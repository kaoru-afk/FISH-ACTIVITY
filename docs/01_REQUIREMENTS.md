# FISH ACTIVITY 要件定義書

- 文書版: 0.1
- 状態: 初版・要件整理中
- 対象: FISH ACTIVITY / SHIKOKU EDITION
- 初期対象エリア: 愛媛県今治市本土（境界は要確定）

## 1. 目的
釣行前に、釣り場・対象魚・日時ごとの環境情報を整理し、釣行判断を支援する。釣行後は釣果だけでなく、釣れなかった釣行や現場観察も記録し、将来の分析に利用できるようにする。釣果を保証せず、利用者の判断を補助する。

## 2. 基本方針
1. 予報値・モデル推定値・実測値・利用者の観察値を区別する。
2. 欠損値をゼロとして扱わない。取得できない値は未取得として保持する。
3. 環境適性スコアを釣果確率と表現しない。
4. 釣れた記録だけでなく、ボウズ・釣行中止・結果不明も区別する。
5. 個人の釣行・釣果記録は本人のみ閲覧・編集できることを基本とする。
6. 魚種プロフィール・釣り場情報には根拠、情報源、確度を持たせる。
7. 数値の単位、取得元、取得時刻、対象時刻を追跡可能にする。

## 3. 想定利用者
- 現段階: 開発者本人による利用・検証。
- 将来: 一般の釣り人。公開時は利用規約、プライバシー説明、データ共有同意を整備する。

## 4. 主要ユースケース
- 日付・エリア・釣り場・魚種を選んで環境情報を確認する。
- 魚種や釣り場に応じた釣行候補を比較する。
- 時間帯別の環境変化を確認する。
- 釣行内容、釣果、ボウズ、現場観察を記録する。
- 記録を魚種・場所・季節・条件別に振り返る。
- 個人情報を除いた分析用データを出力する。

| FR-03 | 時間帯別の環境推移を表示 | 必須 |
| FR-04 | スコア内訳・根拠・欠損要素を表示 | 必須 |
| FR-05 | 魚種または釣り場条件から候補を検索 | 必須 |
| FR-06 | 登録・ログイン・ログアウト | 必須 |
| FR-07 | 釣行記録を保存 | 必須 |

## 6. 非機能要件
- iPhoneを含むスマートフォンのブラウザで操作しやすい。
- 通信失敗・API制限・欠損時に画面が停止せず状態を説明する。
- 公開フロントエンドに秘密鍵を含めない。
- Supabase RLSで個人データを保護する。
- データ取得元・単位・取得時刻を保持する。
- 判定ロジックにバージョンを付ける。

## 7. 対象外・注意事項
- 釣果の保証、確定的な回遊予測。
- 根拠のない潮流・ベイト情報の補完。
- 同意なしの個人釣果データ公開。
- 未確認の釣り場への立入・釣りを推奨すること。

## 8. 未決事項
- 初期対象エリアの正式な境界と釣り場マスター。
- 気象・海洋・潮汐データ提供元と利用条件。
- 一般公開時の利用規約・プライバシー方針。
- 魚種プロフィールの出典・更新責任・確度基準。
- 釣行候補の順位付けとスコア校正方法。
