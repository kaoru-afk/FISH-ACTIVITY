## 2. 釣行結果の状態
- caught: 釣果あり。
- blank: 釣行したが対象となる釣果なし。
- no_fishing: 釣行していない、または中止。ボウズ集計しない。
- unknown: 結果未確定・未入力。

## 3. 検索・絞り込み
- 魚種指定検索では指定魚種だけを候補にする。
- 全魚種指定では対象範囲内の登録魚種を候補にする。
- 釣り場指定時の魚種条件の優先順位は画面仕様として統一する。
- 条件に一致する候補がない場合、別魚種を混ぜず「該当なし」と表示する。
- 適用中の絞り込み条件を画面上に明示する。

## 4. データ表示
- 値には単位を表示する。
- 予報・モデル推定・実測・ユーザー観察を区別する。
- 取得できない値は「未取得」等とし、0と表示しない。
- 対象時刻と取得時刻を可能な範囲で表示する。
- スコアには名称、算出対象、評価時刻、根拠、欠損要素を併記する。

## 5. スコア表示・検索の追加仕様（2026-11-26）
- 環境適合度は風・波・降水等の釣行環境を魚種共通で評価する。
- 魚種別活動期待度は魚種固有の季節・水温要因を評価する。現行初期版では両方が揃った場合のみ算出する。
- 算出できない魚種は「未評価」とし、環境適合度を代用しない。
- 24時間グラフは環境適合度の時間推移として表示する。
- おすすめ釣行プランは活動期待度を算出できる魚種のみ順位付けし、環境適合度と釣り場タイプ適合は別表示する。
- データ充実度は評価済み項目数/対象項目数で表示し、信頼度・精度とは表現しない。

## 6. エラー・例外
- 通信失敗: 再試行可能なメッセージを表示。
- API応答に対象項目がない: 欠損として扱う。
- 認証切れ: 個人データ操作前に再ログインを案内。
- DB書込失敗: 保存成功と誤認させず、エラー表示。
- 検索結果0件: 空状態を表示し、別魚種で埋めない。
