## 2026-11-26 改訂（v0.2）
- 判定ロジックを「環境適合度」と「魚種別活動期待度」に分離。
- 魚種プロフィールが不足する場合は活動期待度を数値化せず「未評価」とする。
- データ充実度の単純百分率を廃止し、評価済み項目数/対象項目数で示す。
- 24時間グラフは環境適合度の推移として扱う。
- おすすめプランは活動期待度が算出できる魚種のみ順位付けし、環境適合度は別情報として併記。
- DBスキーマ変更なし。

## 状態の表記
- 現状: ソースコードまたはSQLで確認できた内容。
- 未検証: 実装は確認できるが、公開環境での動作確認が未完了。
- 予定: 今後の実装候補。現行機能として扱わない。
- 要決定: 根拠や仕様が不足しており、確定が必要。

仕様と実装が食い違った場合は差分を記録し、意図的に仕様を改訂してから実装を変更する。
