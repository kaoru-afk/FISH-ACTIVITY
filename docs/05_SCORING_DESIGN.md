# FISH ACTIVITY 判定ロジック設計書

- 文書版: 0.2
- 改訂日: 2026-11-26
- 状態: 指標分離を実装。係数・魚種プロフィールは暫定で未校正

## 1. 指標の定義

### 1.1 環境適合度（environmentScore）
魚種の活性ではなく、選択地点・時刻の釣行環境を評価する共通指標。現行実装は風速0.40、波高0.40、降水0.20の重みを使用する。取得できた要因だけで重みを再正規化し、欠損値は0点にせず除外する。係数・変換式は暫定ヒューリスティックであり、安全基準や釣果実績から校正された値ではない。

### 1.2 魚種別活動期待度（activityScore）
魚種固有の生態条件を評価する別指標。現行初期版では、根拠のある季節評価と水温評価の両方が数値化できる場合のみ算出し、2要因の単純平均を表示する。片方でも不足する場合はnull（画面上「未評価」）とする。実測活性・釣果確率ではなく暫定的な生態条件スコア。

季節・水温プロフィールが限定的なため、多くの魚種は未評価となる。未評価を0点や環境適合度で代用しない。

### 1.3 総合釣行評価
現行版では環境適合度と活動期待度を単一値に合成しない。統合の重み付け根拠と実釣検証が不足しているため未実装・要決定。

## 2. 入力とデータ品質
- 気象予報: 風速、降水量。
- 海洋モデル: 波高、海面水温。
- 生態プロフィール: 魚種別の季節・水温条件。
- 将来候補: 潮汐、現地潮流、ベイト、マズメ、実釣履歴。
- 予報・モデル・実測・ユーザー観察を区別する。
- 近隣海域モデル値を港内・釣り座の実測値として扱わない。

## 3. 評価項目の充足表示
データ充実度の百分率は廃止し、評価済み項目数/対象項目数を表示する。これは項目の有無であり、精度・信頼度を示さない。根拠不足はmissingFactorsに明示する。

## 4. 画面・機能での利用規則
- 総合判定の主スコアは環境適合度。
- 魚種別一覧は活動期待度を表示し、算出不可は「未評価」とする。
- 24時間グラフ・おすすめ時間は環境適合度の時間変化として扱い、魚種別活性とは呼ばない。
- おすすめプランは活動期待度が算出できる魚種を順位付けし、環境適合度・釣り場タイプ適合は別表示する。
- AI分析用JSONではenvironmentSuitabilityScoreとspeciesActivityExpectationを別フィールドで出力する。
- いずれも釣果確率・釣果保証として表現しない。

## 5. 現行実装の限界
- 季節・水温プロフィールと評価式は一部魚種のみ。
- 風・波・降水の係数は暫定で、実証校正は未実施。
- 季節スコアは月単位の粗い区分。
- 海面水温モデル値は釣り座の水温ではない。
- 潮汐・潮流・ベイト・マズメの魚種別評価は未実装。
- 項目充足数は信頼度を表さない。

## 6. 検証・改善
- 釣果ありだけでなくボウズも含め、no_fishingとblankを混ぜない。
- 釣行時間・釣り方・対象魚・場所・努力量を考慮する。
- 予測時点のスコアを保存し、後ろ向き・前向き検証する。
- 十分な標本数・校正・評価指標が整うまでは確率表示しない。

## 7. 未決事項
- 魚種別プロフィールの出典・確度・地域適用性。
- 季節・水温以外の活動要因の定義と評価。
- 環境適合度と活動期待度を統合する必要性・方法。
- 校正に必要な標本数と評価指標。
- 環境適合度の係数を釣法・釣り場タイプ別に調整するか。
