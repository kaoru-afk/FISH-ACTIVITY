# FISH ACTIVITY 判定ロジック設計書

- 文書版: 0.1
- 状態: 原則確定・計算式は検証中

## 1. スコアの意味を分離する
1. **環境適性**: 風・波・降水・水温等が釣行条件としてどの程度適しているか。
2. **魚種別活性期待**: 季節、生態、水温、潮汐、ベイト、時間帯等から、その魚種の活動条件がどの程度そろっているか。
3. **総合釣行評価**: 環境適性と魚種別活性期待を統合した釣行判断用指標。

これらは釣果確率ではない。実測データによる校正が完了するまでは「釣れる確率」「釣果率」と表示しない。

## 2. 入力データ
- 気象予報: 風速、風向、降水、気温、気圧、雲量等。
- 海洋モデル: 海面水温、波高、海面高度、流向・流速等。
- 潮汐: 潮位、潮時、潮差等。
- 生態プロフィール: 季節性、水温帯、対象地域、活動時間等。
- 現場観察: ベイト、実際の潮の動き、水色、水温、波等。
- 実釣履歴: 釣行時間、釣り方、釣果、ボウズ、釣行中止等。

## 3. 計算原則
- 魚種ごとに根拠のあるプロフィールを用いる。
- プロフィール未登録の魚種に他魚種の条件を流用しない。
- 欠損項目を中立点や0点として埋めない。
- 使用項目・重み・変換式・入力値・単位を保存する。
- スコアにアルゴリズムバージョンを付ける。
- データ品質/評価項目の充足度をスコア本体と分離する。
- 同じ入力と同じバージョンなら同じ結果になること。

## 4. 現行実装
現行フロントエンドには魚種評価・環境条件評価の処理が存在する。ただし、係数・重み・魚種別プロフィールが実釣データで十分に校正されたとは確認できない。現行スコアは暫定的なヒューリスティック評価として扱い、科学的に検証済みの魚の活性値や釣果確率とは表現しない。

## 5. 表示仕様
各評価結果に指標名と意味、尺度、対象魚種・場所・日時、入力項目と値・単位、欠損項目、データ取得元・取得時刻、アルゴリズムバージョン、釣果を保証しない旨を含める。

## 6. 検証・改善
- 釣果ありだけでなく、ボウズの釣行も含める。
- 釣行時間・釣り方・対象魚・場所・努力量を考慮する。
- no_fishingとblankを混ぜない。
- データ量が少ない魚種・場所では統計的な断定をしない。
- 過去データで後ろ向き検証し、運用中の予測を保存して前向き検証する。
- 確率表示は十分な標本数・校正・評価指標を満たした別モデルとして設計する。

## 7. 未決事項
- 魚種別プロフィールの標準項目と信頼できる出典。
- 時間帯・潮汐・ベイト要素の定義と評価方法。
- 環境適性と魚種別活性期待の統合方法。
- 校正に必要な最低データ数と評価指標。
